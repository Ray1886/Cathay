# 突发修改与恢复引擎

已整合到主界面的「突发修改」入口，不需要 npm 依赖。运行 `node server.js`，打开 http://127.0.0.1:8765/ 。测试：`node --test`；固定场景：`node recovery/demo.js`。

## 已实现

- 晚到分钟以原计划为基线，也可提供包含日期的预计到达时间，支持跨午夜。
- 模拟登机口变化、起飞延误和独立登机时间变化。起飞延误不会自动延后登机。
- 香港时区完整时间、字段版本、事件幂等和乱序检查。
- 确定性恢复规则保留可行活动，检查时长、重叠、步行、贵宾室转移及登机缓冲；未知路线不猜测。
- 航班事实先更新；活动只生成预览。取消草案保留事实与风险提示，确认后才保存浏览器行程。
- 确认核对旅程和活动签名，再校验约束与候选库存。过期、变更或服务重启后须重新预览。
- SQLite 只读适配器核查本机示范空位。改期的已确认服务降为待确认；移除不自动取消实际预约。
- DeepSeek 解释恢复结果，不能改变引擎草案。AI 失败仍可生成和确认本地恢复建议。

## 边界

路线、航班、会员及库存均为示范数据，未接真实航空 API。恢复算法是保守的局部调整，不保证全局最优。未知地点路线或无法核查空位时可能移除活动并提示人工处理。桥堂暂无 SQLite 映射，不会凭空返回可预约时段。

旅程与行程保存在浏览器 localStorage；服务端草案缓存最多 100 个，10 分钟过期，重启不保留。旧 HH:MM 活动以计划到达日为锚点，开始时间倒退超过 12 小时才视为跨午夜；复杂多日活动须明确提供 startAt/endAt。

密钥通过终端隐藏输入，仅驻留本地服务内存。DeepSeek 配置状态不等于认证成功，实际得到回复才完成验证。预约创建、取消、换约事务不属于恢复确认；本轮只保存行程。
