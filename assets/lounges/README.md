# Official Cathay lounge photography

All five photos are sourced from Cathay Pacific's own lounge pages, not generated images or stock approximations. Files retain the original JPEG image data without recompression; source and copyright information has been added as standard EXIF metadata.

- `pier-first-shower.jpg`: The Pier, First — shower suites.
- `wing-first-dining.jpg`: The Wing, First — The Dining Room.
- `pier-first-massage.jpg`: The Pier, First — massage service.
- `pier-first-rest.jpg`: The Pier, First — day suites.
- `pier-first-work.jpg`: The Pier, First — The Bureau (available for future presentation of the existing work activity).

Official pages:

- https://www.cathaypacific.com/cx/en_HK/destinations/lounges/hong-kong-hkg/the-pier-first.html
- https://www.cathaypacific.com/cx/en_HK/destinations/lounges/hong-kong-hkg/the-wing-first.html

`sources.json` records each original image URL, official page, subject, retrieval date, original download hash and final file hash. Rights remain with Cathay Pacific; this directory does not claim an open-source license for the photographs. Photos are attributed in the prototype. Photography does not establish inventory, eligibility or reservation rules; those remain the existing synthetic demo model.

The previously generated `lounge-scenes.png` and `lounge-hero.png` have been removed. Current service cards use real image elements with descriptive alternatives and lazy loading.
