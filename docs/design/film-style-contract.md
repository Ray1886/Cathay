# Film appearance → working app

## Direction

Operate mode. The user has already selected the visual reference; no new concept round is needed. Build code-first against the existing short-film screens. Main reference: ../../../../output/pitch-clips-v3/keyframes/01-voice-planning-06.jpg; assistant reference: ../../../../output/pitch-clips-v3/keyframes/01-voice-planning-04.jpg; recovery reference: ../../../../output/pitch-clips-v3/keyframes/03-late-arrival-recovery-04.jpg.

## First viewport

A compact white navigation header, understated flight strip and softly tinted time context lead into an open timeline. Time values, activity names, venue and booking state are distinct. Keep real current CX251 data; copying the film's CX880 data would change project behavior. Scrolling is native and the tab bar remains fixed.

## Cross-surface system

System-first typography (PingFang/SF on Apple devices), 21px screen titles, 18px section headings, 16px activity labels, 15px body, 12px supporting information. Teal #23635b, ink #213b34, sage #edf3ef, canvas #f4f6f2. Muted text is adjusted slightly darker than the film for web readability. Use flat list rows and 14–16px grouping corners; sheets 26px top corners. No decorative shadows or fake iOS status chrome inside the app.

Both screens share three bottom destinations/actions: 我的行程, 智能助手, 突發修改. Existing save, time management, booking/waitlist and five assistant capabilities remain accessible in their relevant context. The four-point assistant mark is preserved. AI replies remain white framed bubbles, user replies pale sage. Composer, sheets, reservation panels and proposal confirmation share the same control vocabulary.

## Signature interaction

Short directional screen entry and bottom-sheet presentation, immediate restrained button press feedback, reduced-motion fallback. Existing voice recognition/fallback and send semantics remain unchanged. No synthetic successful speech-recognition or booking state is introduced.

## Photographs

Replace the existing service imagery with original JPEGs fetched from Cathay's official The Pier First and The Wing First pages. Keep a text-led itinerary. Use clear actual image alternatives and traceable origins; photograph choice does not redefine service eligibility or real reservation rules.

## Preserve

No business-rule, database, API contract, AI prompt, reservation execution, authentication or recovery-algorithm change. Existing element IDs / data action hooks are retained when controls move. Only public image paths may be added to server static allowlisting. Current main startup and Pages safeguards remain.

## Acceptance

Exercise manual edit/save/reorder, planner ↔ assistant navigation, booking sheet/tab/filter, comparison/recommendation, incident entry, proposal preview/confirmation; all existing tests and static Pages build must pass. Check mobile 390×844, narrow 320px, desktop and the user's actual browser width. Finish review uses screenshots and the pinned reference frames. Real iPhone touch/keyboard behavior requires physical-device follow-up; browser emulation is not device evidence.
